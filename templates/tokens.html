🔑 API Token

Token dipakai untuk memanggil API tanpa login browser, lewat header Authorization: Bearer <token>. Token bertindak dengan role akun Anda ({{ user.role if user else '' }}). Perlakukan seperti password.

Token berhasil dibuat. Salin sekarang, nilainya tidak akan ditampilkan lagi.
